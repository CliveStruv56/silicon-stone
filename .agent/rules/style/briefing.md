# Briefing variant (canonical)

> Inherits all rules in [[house-style]]. This file adds only what is specific
> to the Briefing variant. Canonical — synced into the website repo, not edited there.

## Purpose

- Standard analytical depth — the default Stone Briefing tier, used to track weekly news events and policy changes.

## Length & structure

- **Target length:** `800–1,500 words` (corresponds to the `Signal` content type in the repo).
- **Structure:** Title, Subject Line, Preview Text, Methodology Audit (2–4 cells), Main Body (clearly divided sections), and the closing Stone Truth Callout.

## Tone & depth

- Intermediate analytical depth, applying 2 to 4 cells of the 3×2 matrix. Sober, considered, and weighty register.

## Must include / must avoid

- **Must include**: Methodology Audit (2–4 cells), Stone Truth Callout, and cited primary sources.
- **Must avoid**: Misalignment between the Methodology Audit checked cells and what the body actually delivers (under-claiming or over-claiming).

## Brand notes

- Silicon & Stone use: Default format for the Tuesday Stone Briefing.
- Waymark Path use: Standard analysis for career paths or skill transitions (typically published as Friday Practical Moves).
